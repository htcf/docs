# Advanced Workflows

End-to-end examples for domain-specific research applications.

## Available Workflows

### [Machine Learning and Deep Learning](machine-learning.md)
Complete ML/DL pipeline with PyTorch and TensorFlow. Train neural networks on GPU, implement data parallel training, and optimize hyperparameters.

**GPU:** Required | **Level:** Advanced
**Includes:** Single-GPU training, multi-GPU, hyperparameter tuning, checkpointing

### [Bioinformatics Pipelines](bioinformatics.md)
RNA-seq, variant calling, and assembly workflows optimized for HPC. Process sequencing data efficiently with array jobs.

**GPU:** Optional | **Level:** Advanced
**Includes:** Quality control, alignment, variant calling, annotation

### [HPC Applications](hpc-applications.md)
MPI-based parallel computing and scientific simulations. Scale across multiple nodes for large computational problems.

**GPU:** Optional | **Level:** Advanced
**Includes:** MPI setup, multi-node jobs, scaling strategies

## Workflow Structure

Each workflow includes:

- **Overview** - Use case and requirements
- **Software setup** - Installation and configuration
- **Complete examples** - Working code you can run
- **Job scripts** - Batch submission templates
- **Optimization tips** - Performance improvements
- **Troubleshooting** - Common issues and solutions
