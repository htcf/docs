## Getting Help

For assistance with the HTCF cluster:

1. **Check the documentation** - Search this site for relevant topics using the search box
2. **Review troubleshooting** - See the [Troubleshooting Guide](../troubleshooting/index.md) for common issues
3. **Check the FAQ** - Many common questions are answered in the [FAQ](../troubleshooting/faq.md)
4. **Ask on Slack** - Post questions in the **#general** channel with the following information:
   - Username
   - Job ID (if applicable): `$ squeue -u $USER`
   - Error messages (copy/paste from log files)
   - Steps to reproduce the issue
   - For running/completed jobs: `$ scontrol show jobid -dd <JOBID>`

!!! info "Slack Support"
    Post questions and requests in the **#general** Slack channel for help from HTCF staff and the community.
